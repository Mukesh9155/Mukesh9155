## 👨‍💻 About me

I'm a **Technical Project Manager at TQS Logistics** and a hands-on **full-stack developer** with **3+ years** of experience in **React, Next.js, TypeScript and JavaScript**. I lead TQS's IT projects, from the ERP the operations team uses all day to the mobile apps our customers and sales team carry, and I still write a lot of the code.

I build scalable, responsive, user-focused applications with reusable component architecture, REST APIs, authentication, role-based access control (RBAC), state management and frontend performance optimisation. I work closely with backend developers, UI/UX designers and QA engineers to ship reliable, production-ready features.

- 🧩 **Web:** React, Next.js and TypeScript apps with reusable components, REST APIs, authentication, RBAC, SEO and fast, responsive UIs
- 📱 **Mobile & desktop:** cross-platform Flutter apps, plus desktop modules in C#, .NET and MFC
- ⚙️ **Backend & real-time:** Node.js / NestJS REST APIs, WebSockets, MQTT and AWS IoT Core
- 🚢 **Delivery:** CI/CD with GitHub Actions and AWS, so every release is checked before it goes live
- 🤖 **AI-assisted development:** Generative AI, LLMs and prompt engineering for code generation, debugging, refactoring and documentation, while keeping code reviewed, typed and tested
