## 👨‍💻 About me

I'm a **full-stack developer at TQS Logistics**, where I build the software the business runs on, from the ERP our operations team uses all day to the mobile apps our customers and sales team carry in their pockets.

- 🧩 **Web:** React, Next.js and TypeScript front-ends for complex operations: shipment (AWB) booking and tracking, customer rate cards, billing and live dashboards
- 📱 **Mobile:** Flutter apps for customers (orders, pickups, live tracking) and for the sales team
- ⚙️ **Backend & delivery:** NestJS APIs, plus CI/CD with GitHub Actions and AWS so every release is checked before it goes live
- 🤖 **AI-assisted development:** I use AI tools to move faster while keeping code reviewed, typed and tested
